# Sold listings — raw Zillow source

Verbatim text pasted from each home's public Zillow page during the build of `/sold/`.
Kept here as a backup of the source material in case we want to surface details we
didn't extract into `src/data/solds.json` (for example: school ratings, walkability scores,
the listing description, prior-owner stories).

These are the **public** Zillow listing detail pages, accessed by anyone visiting the
URL — not private data. Each file's frontmatter includes the `zpid` and `zillow_url`
for cross-referencing back to `src/data/solds.json`.

Captured: 2026-05-05.
